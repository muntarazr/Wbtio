# مجلد الأغلفة

الصفحة (`index.html`) تدوّر على الغلاف باسم رقم المسلسل + `.jpg`:

```
images/001.jpg   ← القصر الشرقي
images/002.jpg   ← The East Palace
images/032.jpg   ← الأكمام الحمراء
...
images/087.jpg   ← الاميرة جاميونغ
```

الأرقام مطابقة لأرقام الصفوف بملف [`../WATCHLIST.md`](../WATCHLIST.md).

## شلون تجيب الأغلفة

**الطريقة الأولى — السكربت (أسرع):**
```bash
python3 tools/download_posters.py
```
يقرأ الروابط من `links.txt` وينزّلهن هنا بالأسماء الصحيحة تلقائياً.

**الطريقة الثانية — يدوي:**
نزّل الصورة وسمّها برقم المسلسل، مثلاً `032.jpg`، وحطها بهذا المجلد.

## إذا الغلاف مو موجود

ما تنكسر الصفحة — يظهر غلاف بديل مصمّم تلقائياً بلون ورمز حسب نوع المسلسل
(اكشن = سيوف، دراما = قمر، تاريخي = سقف قصر، خيالي = نجوم... إلخ)، وعليه اسم المسلسل.
أول ما تنزّل الغلاف الحقيقي يحل محله فوراً بدون أي تعديل بالكود.
