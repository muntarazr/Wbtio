# مجلد الأغلفة

فيه **87 غلاف** — كل مسلسل بالقائمة إله غلافه، مسمّى برقمه:

```
images/001.jpg   ← القصر الشرقي
images/032.jpg   ← الأكمام الحمراء
images/087.jpg   ← الاميرة جاميونغ
```

الأرقام مطابقة لأرقام الصفوف بملف [`../WATCHLIST.md`](../WATCHLIST.md).
ملف [`mapping.json`](mapping.json) فيه الربط الكامل بين كل رقم واسم المسلسل واسم الملف الأصلي.

## المواصفات

- الحد الأقصى للعرض: **500 بكسل** (JPEG تدريجي، جودة 84)
- الحجم الكلي: ~5.9 ميغابايت (الأصل كان 22.2 — انضغطت بدون فرق ملحوظ بالجودة)

## استبدال أي غلاف

نزّل الصورة الجديدة وسمّها برقم المسلسل (مثلاً `032.jpg`) وبدّلها هنا — الصفحة تلتقطها تلقائياً.

أو استخدم السكربت مع رابط جديد بملف `links.txt`:
```bash
python3 tools/download_posters.py --force
```
