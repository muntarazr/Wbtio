## شنو هذي

لوحة يومية وأسبوعية وشهرية لمسار سنتين نحو كوريا الجنوبية. تشتغل كلياً بمتصفحك،
وتبقى شغالة بعد ما ينتهي أي اشتراك — لأنها ما تعتمد على أي خدمة خارجية.

| الشاشة | شنو تسوي |
|---|---|
| **اليوم** | اليوم الأدنى (أربع ساعات) · جدول البلوكات · دقائق اللغة · أقرب خمس مهام |
| **المهام** | 136 مهمة ببذرة النظام + مهامك أنت · وقت مقدَّر مقابل فعلي · ملاحظات |
| **الأسبوع** | ستة مؤشرات رقمية مقابل أهدافها · مراجعة الأحد |
| **الشهر** | هدف الشهر من الـ24 · التقدم · الطريق كامل |
| **الدخل** | كل دفعة · مجموع شهري · الادخار مقابل شرط أصول F-2-7 |
| **العملاء** | pipeline خفيف · إبراز المتابعات المتأخرة بالأحمر |
| **كوريا** | حاسبة نقاط F-2-7 حية · 14 معلماً بالمسار |
| **الانضباط** | نسبة الأيام الكاملة · السلسلة · شبكة 90 يوم · قاعدة التعافي |
| **الإعدادات** | الثيم واللون والخط والحجم والكثافة · إظهار وإخفاء وترتيب الأقسام · تصدير واستيراد |

## ⚠️ النسخة الاحتياطية — اقرأ هذا

**كل بياناتك بمتصفحك أنت فقط** (`localStorage`). يعني:

- تنمسح لو مسحت بيانات المتصفح أو استخدمت وضع التصفح الخفي.
- ما تنتقل معك لجهاز ثاني إلا بالتصدير.
- ما أحد ثاني يشوفها — ولا أنا ولا أي خادم.

**كل أحد بعد مراجعة الأسبوع:** الإعدادات ← تصدير JSON ← احفظ الملف بمكان ثاني
(درايف، إيميل لنفسك، فلاش). اللوحة راح تنبّهك تلقائياً إذا مرّ أسبوع بلا نسخة.

الاستيراد يستبدل كل شي، فما تستورد إلا لو متأكد.

ملف التصدير مُصمَّم ليُربط لاحقاً بقاعدة بيانات. كل سجل عنده `id` فريد و`createdAt`.

  "settings": { "theme": "auto|light|dark", "accent": "#RRGGBB", "font": "system|tahoma|serif|mono",

                "visible": { "<sectionId>": true }, "order": ["today", "..."],
                "krw": 1380, "startDate": "YYYY-MM-DD" },

                            "notes": "", "doneAt": "ISO", "deleted": false } },

                     "t": "العنوان", "why": "", "st": [], "dw": "", "est": 60 } ],

                                        "clients": false, "build": false },
                              "englishMin": 60, "koreanMin": 60,
                              "uniDay": false, "note": "" } },
  "weeks":  { "YYYY-MM-DD": { "proposals": 0, "messages": 0, "applications": 0,
                              "replies": 0, "calls": 0, "posts": 0, "note": "" } },

  "income":  [ { "id": "...", "date": "YYYY-MM-DD", "client": "", "amount": 850 } ],

## الملفات

```
dashboard/
├── index.html          الهيكل — افتحه
└── assets/
    ├── style.css       كل الألوان عبر متغيرات CSS، والإعدادات تغيّرها وقت التشغيل
    ├── data.js         الثوابت: البلوكات · 24 سبرنت · معالم كوريا · جدول F-2-7
    ├── tasks.js        قاعدة المهام (136 مهمة)
    └── app.js          المنطق — الحالة والحفظ والعرض
```

**ليش `data.js` و`tasks.js` ملفات JS مو JSON؟** لأن `file://` يمنع `fetch`،
واللوحة لازم تُفتح بالنقر المزدوج بلا خادم. هذا قرار مقصود.

## تعديل النظام بنفسك

- **مهمة جديدة:** المهام ← زر «+ مهمة». تُحفظ بـ`customTasks`.
- **تعديل الوقت المقدَّر:** افتح تفاصيل المهمة وغيّر الرقم — تعديلك يعلو على البذرة.
- **مهمة ما تناسبك:** «حذف من قائمتي» — مهام البذرة تُخفى ولا تُمسح من الملف.
- **إضافة سبرنت أو معلم:** عدّل `assets/data.js` مباشرة.
- **إضافة مهام كثيرة دفعة وحدة:** عدّل `assets/tasks.js` بنفس الشكل.
