## المميزات

- **تعليم المشاهدة** — اضغط الختم الأحمر على أي غلاف؛ السجل ينحفظ بالمتصفح (localStorage)
- **بحث وفلترة** — بالاسم أو القصة، حسب النوع، حسب المشاهدة
- **ترتيب** — الأعلى تقييماً، الأحدث، الأقدم، أبجدي
- **إحصائيات** — كم شفت، متوسط تقييمك، نوعك المفضّل
- **تصدير** — زر «اطلع قائمتي» يطلع قائمة نصية جاهزة للنسخ
- **أغلفة بديلة مصمّمة** — كل نوع له لون ورمز بصري خاص إذا الغلاف الحقيقي ما انحمّل

## تعديل البيانات

- **تغيير معلومات مسلسل** — عدّل سطره بملف `assets/data.js` (سطر واحد لكل عمل: الرقم، الاسم، السنة، التقييم، النوع، القصة).
- **استبدال غلاف** — سمّي الصورة برقم المسلسل (مثلاً `032.jpg`) وبدّلها بمجلد `images/`؛ الصفحة تلتقطها تلقائياً.
- **تنزيل الأغلفة من جديد** — حدّث الرابط بملف `tools/links.txt` وشغّل:
  ```bash
  python3 tools/download_posters.py --force
  ```
  الأغلفة الحالية بعرض أقصاه 500 بكسل (JPEG تدريجي، جودة 84).
