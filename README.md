# 📺 سجل المسلسلات الكورية التاريخية

مستودع لتتبّع المسلسلات الكورية التاريخية (ساگوك) — شنو شفت وشنو باقي.

## الملفات

| الملف | الوصف |
|-------|-------|
| [`WATCHLIST.md`](WATCHLIST.md) | القائمة الكاملة (87 عنوان) مع القصة والتقييم والسنة والنوع + عمود للتعليم على اللي شاهدته |

## طريقة العمل

1. افتح [`WATCHLIST.md`](WATCHLIST.md)
2. بدّل `☐` إلى `✅` بعمود **"شاهدته؟"** لكل مسلسل شفته
3. رجّع القائمة معلّمة → راح ينبني ملف بالمسلسلات المشاهَدة + إحصائيات + اقتراحات للمشاهدة الجاية

## حالة القائمة

- **87** صف بالقائمة
- **83** عمل مختلف فعلياً (4 مكرّرات بترجمات مختلفة — مذكورة بآخر `WATCHLIST.md`)
- **5** أعمال محتاجة تأكيد الاسم الأصلي
