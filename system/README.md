## ملفات مولَّدة آلياً — لا تعدّلها يدوياً

`TASKS.md` و`MONTHLY-SPRINTS.md` **تُولَّدان** من `../dashboard/assets/{data,tasks}.js`:

```bash
node system/generate-docs.mjs
```

**عدّل المصدر أو اللوحة، ثم أعد التوليد.** التعديل اليدوي يضيع بأول توليد.

## التشخيص الذي يحكم هذا المجلد

سجلّك يناقض وصفك لنفسك: ثلاث منصات بالإنتاج بسبعة أشهر وقيادة قسم IT وCS50x
**ليست مخرجات شخص بلا انضباط**. النمط الحقيقي: **إنجاز عالٍ داخل هيكل خارجي،
وتعثّر بالأهداف مفتوحة النهاية.**

> **المشكلة ليست أنك تتوقف — بل أن لا شي يجعل توقفك مكلفاً.**
> الحل: [`../goal/THE-WINDOW.md`](../goal/THE-WINDOW.md) — صناعة التزامات خارجية مؤرَّخة.

**مقياسك الذي حدّدته بنفسك: ≥ 70% من الأيام يكتمل فيها اليوم الأدنى.**
تقرأه من شاشة الانضباط في [`../dashboard/index.html`](../dashboard/index.html).
