# دليل المهارات — أيها يفيدك، وأيها يضيّع وقتك

> **ليش هذا الملف:** سوق المهارات فيه آلاف، وأغلبها **لا يخصّك**. تثبيت مهارة لا تحتاجها
> ليس مجانياً — يزاحم انتباه المساعد، ويكبّر المستودع، ويخلق ثقة زائفة بأن «الأداة موجودة».
> هنا **حكم صريح على كل مهارة فحصتها**، ومعياره حالتك أنت لا شعبيتها.
>
> **آخر تحديث:** 2026-08-21 · **الفحص:** من المصدر (`npx skills add <repo> -l`) لا من الوصف

## 1. المعيار — أربع مسارات فقط

المهارة تدخل إذا خدمت أحد هذي، **وإلا تُرفض مهما كانت جيدة**:

| # | المسار | ليش |
|---|---|---|
| 💰 **الشغل** | تسليم أسرع وأقل أخطاء لعميل يدفع | الدخل شرط فيزا لا رفاهية |
| 📚 **الدراسة** | IELTS تشرين الثاني 2026 · TOPIK | بوابة القبول ونقاط F-2-7 |
| 🔍 **البحث** | تحقق من مصدر رسمي بتاريخ وثقة | قرار سنتين لا يُبنى على ظن |
| 🇰🇷 **كوريا** | وثائق · مواعيد · تقديم | الهدف نفسه |

**وثلاثة شروط قاطعة:** مجانية بالكامل (ميزانيتك صفر) · تشتغل بلا خدمة محجوبة بالعراق ·
مصدرها موثوق (المهارة **تعليمات تُنفَّذ بصلاحياتك الكاملة**، لا ملف قراءة).

| المهارة أو الصنف | الحكم | السبب |

| `vercel-cli-with-tokens` | 🟡 **مؤجلة** | لما تنشر لعميل بحسابه هو، لا الآن |
| `vercel-composition-patterns` · `writing-guidelines` | 🟡 **مؤجلة** | نافعة لكن ليست عنق زجاجة — أضفها لو صار كودك يُراجَع من غيرك |
| **مهارات البحث الأكاديمي** (deep-research وأمثالها) | 🟡 **مؤجلة بتاريخ** | تدوّر أوراقاً علمية، وبحثك اليوم **فيزا وأسعار لا أوراق**. ✅ **افتحها عند مهمة `K10`** — مقترح البحث ومراسلة الأساتذة |

| مهارات نشر على منصات محجوبة بالعراق | ❌ | نفس منطق `income/RAILS.md` — لا تبنِ على قناة مقطوعة |

## 4. 🔍 الفجوات — ما لا توجد له مهارة، وتبنيه أنت

**أهم قسم بالملف.** هذي احتياجاتك الحقيقية التي **لا يغطيها السوق**، فبناؤها محلياً
أعلى عائد من أي تثبيت:

| الفجوة | الحالة | الخطوة |
|---|---|---|
| **كوريا: وثائق ومواعيد وتصديق قنصلي** | ⬜ لا توجد | ابنِ `korea` محلياً — يقرأ `VERIFY-PROTOCOL` ويولّد أسئلة السفارة |
| **n8n وأتمتة LLM** | ⬜ لا توجد جيدة | تخصصك الأعلى سعراً — تكتبها من شغلك الفعلي |
| **الانضباط والمراجعة الأسبوعية** | ⬜ لا توجد | تُبنى فوق `system/WEEKLY-CYCLE.md` |

**اكتبها بـ`skill-creator` (مدمجة).** والقاعدة: **مهارة لكل عمل تكرر ≥ 3 مرات**، لا أقل.

## 5. كيف تثبّت وتشيل

```bash
npx skills add <owner>/<repo> -l                        # اعرض ما فيه قبل التثبيت — إلزامي
npx skills add <owner>/<repo> -s <name> -a claude-code -y --copy   # ثبّت واحدة بالمستودع
npx skills list                                          # المثبَّت
npx skills remove <name>                                 # شيل
```

| القاعدة | ليش |
|---|---|
| **`-l` قبل كل تثبيت** | تقرأ الوصف من المصدر لا من صفحة تسويق |
| **`--copy` دائماً** | ينسخ بدل symlink — ينحفظ بالمستودع ويشتغل offline |
| **`-a claude-code`** | بلاه يثبّت لوكلاء لا تستعملهم |
| **مشروعي لا `-g`** | يبقى بالمستودع، ويُدفع مع بقية الشغل |
| **افتح `SKILL.md` قبل الاستعمال** | تُنفَّذ بصلاحياتك الكاملة |
| **مهارة ما استعملتها بشهر — شيلها** | المستودع مو مخزن |

> ⚠️ **سجل `skills.sh` محجوب** من بيئات العمل هذي — `npx skills find` يرجع فارغاً.
> **التثبيت من GitHub يشتغل**، فاذكر المستودع بالاسم مباشرة.

## 6. قبل ما تثبّت أي مهارة جديدة — خمسة أسطر

- [ ] تخدم أحد المسارات الأربعة **بالاسم**؟
- [ ] مجانية بالكامل، وبلا خدمة محجوبة بالعراق؟
- [ ] **مو مدمجة أصلاً** بـClaude Code؟
- [ ] مصدرها أول-طرف (الشركة صاحبة الأداة) أو راجعت `SKILL.md` بنفسك؟
- [ ] راح تستعملها **هذا الشهر**؟ إذا لا — 🟡 مؤجلة، ما تُثبَّت

**خمسة نعم = ثبّتها وسجّلها بالقسم 2. أي «لا» = لا تثبّتها، وسجّل السبب بالقسم 3.**
