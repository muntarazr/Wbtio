# منتج ١ — فرز البريد والرد التلقائي (AI Inbox Triage)

> **الفكرة:** تبنيه مرة، تبيعه عشر مرات. كل عميل جديد = تعديل بلوك `<business>` بالبرومبت + ربط حساباته. باقي الشغل صفر.

---

## شنو يسوي بالضبط

كل رسالة تجي للعميل (إيميل / واتساب / نموذج الموقع) تمر بنفس المسار:

```
رسالة داخلة → توحيد الشكل → تصنيف بالـ AI + مسودة رد → توجيه
                                                          ├─ رد تلقائي فوري
                                                          ├─ تصعيد لموظف بشري
                                                          └─ إسقاط (سبام)
                                     كل شي ينحفظ بجدول Google Sheets
```

الـ AI يرجّع ستة حقول ملزمة: `category` · `urgency` · `language` · `summary` · `needs_human` · `reply`.

**القرار مو للموديل وحده.** الرسالة تروح لبشري إذا الموديل رفع العلم، **أو** كانت `urgency = high`، **أو** كانت شكوى — حتى لو الموديل قال إنه يگدر يتصرف. هذا اللي يخلي العميل يوافق يشغّلها على بريده الحقيقي.

## ليش هذا المنتج بالذات

| السبب | التفصيل |
|---|---|
| **الألم واضح ومقاس** | صاحب العمل يعرف بالضبط قد إيش رسالة تضيع عليه بالأسبوع |
| **النتيجة تنقاس** | "٦٨٪ من الرسائل انسكرت بدون تدخل بشري" — رقم من الـSheet مو ادعاء |

| **قابل لإعادة البيع كلياً** | نفس الـworkflow، بس بلوك نص يتغير |
| **يشتغل بأي لغة** | ميزة مباشرة بالسوق العراقي والخليجي — الموديل يرد بلغة الزبون |

## العرض بمكالمة المبيعات (٦٠ ثانية)

هذا أهم جزء. **لا تشرح — ورّي.**

```bash
export ANTHROPIC_API_KEY=sk-ant-...
python3 demo/run_demo.py
```

يطبعلك كل رسالة، تصنيفها، القرار، والرد المقترح، وبالآخر: *"٢ من ٤ رسائل انسكرت بدون تدخل بشري."*

**الحركة القاتلة:** بالمكالمة، اطلب من العميل يعطيك ٣ رسائل حقيقية من بريده. حطها بملف JSON بنفس شكل `sample-messages.json` وشغّل:

```bash
python3 demo/run_demo.py client-messages.json
```

يشوف نظامه هو، برسائله هو، قدامه. هذا يقفل الصفقة أسرع من أي بورتفوليو.

## التكلفة الحقيقية عليك

الموديل haiku، ورسالة نموذجية بحدود ٤٠٠ توكن دخل و٢٠٠ خرج. حتى بألف رسالة بالشهر تكلفة الـAPI تبقى بضعة دولارات. الاستضافة: n8n على VPS رخيص أو n8n Cloud.

يعني **هامشك على الريتينر يقرب ٩٥٪**، ورأس المال المطلوب لإطلاق هذا المنتج = سعر مفتاح API واستضافة.

## نشره على GitHub

هذا المجلد هو أول مستودع محترم إلك. عند النشر:

1. مستودع منفصل باسم `n8n-inbox-triage`.
2. الـREADME بالإنكليزي (انسخ من `SETUP.md` وزيد عليه صورة للـworkflow).
3. **راجع قبل الرفع:** ما يكون بيه مفتاح API، ولا معرّف Sheet حقيقي، ولا اسم عميل. كل الأماكن الحساسة مكتوب بيها `REPLACE_ME` — خليها هيچي.
4. ضيف الرابط بالبورتفوليو وبالسيرة الذاتية وبرسائل التواصل.

كود شغّال على GitHub يبيع أكثر من أي سطر بالسيرة الذاتية.
