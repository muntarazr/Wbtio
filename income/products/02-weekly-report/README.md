شنو يستاهل انتباه · **ثلاث خطوات لهالأسبوع** · أعلى الفئات والزبائن.

## القرار الهندسي الذي يجعله يُباع

> ## **الحساب بالكود. السرد بالنموذج. ولا العكس أبداً.**

عقدة `Compute Metrics` تحسب **كل رقم**. النموذج يستلمها محسوبة، ومكتوب له صراحةً
ألا يعيد حسابها. وقالب الإيميل يقرأ الأرقام **من عقدة الحساب** لا من نص النموذج —
فحتى لو هلوس النموذج برقم داخل جملة، **الجدول يبقى صحيحاً**.

**ليش هذا يهم تجارياً:** النماذج اللغوية تخطئ بالحساب. وصاحب العمل الذي يمسك عليك
رقماً خاطئاً واحداً، يتوقف عن تصديق كل رقم بعده — وتخسر الريتينر كله.

هذي الجملة نفسها **قلها بمكالمة المبيعات**. أغلب من يبيعون «تقارير بالذكاء الاصطناعي»
يمرّرون البيانات الخام للنموذج ويطلبون منه التحليل. أنت تشرح ليش هذا خطر، وتشرح ماذا
فعلت بدلاً منه — وهذا وحده يفرّقك.

**تفاصيل إضافية بالتنفيذ:**
- نسبة التغير تُحسب فقط لو كانت القاعدة غير صفرية — وإلا يظهر «نمو ∞%» ويفضح النظام
- الصفوف بتواريخ غير مقروءة تُعدّ وتُذكر بذيل التقرير بدل أن تُبتلع بصمت
- العملة دائماً بمنزلتين — `$2,871.5` يُقرأ كخطأ تنسيق ويشكّك بالباقي

## العرض بمكالمة المبيعات

```bash
node demo/run_demo.mjs --metrics-only     # الأرقام فقط، بلا API
export ANTHROPIC_API_KEY=sk-ant-...
node demo/run_demo.mjs                    # التقرير كامل → demo/report.html
```

**الحركة القاتلة:** اطلب من العميل تصدير آخر أسبوعين من متجره أو جدوله كـJSON بأربعة
حقول (`date` · `amount` · `category` · `customer`)، وشغّل:

```bash
node demo/run_demo.mjs client-data.json
```

يشوف تقريره هو، بأرقامه هو، خلال دقيقة. **بياناته لا تخرج من جهازك** إلا لاستدعاء
النموذج — وهذي نقطة تُقال بصوت عالٍ لأن العميل يسألها.

> بيانات العرض المرفقة تُنتج حالة ممتازة للبيع: الإيراد نزل 22% بينما الطلبات زادت 17%.
> أي صاحب عمل يشوف هذا يسأل فوراً «ليش؟» — وهذي بالضبط اللحظة التي يشتري فيها.

| | فرز البريد | التقرير الأسبوعي |
|---|---|---|
| مخاطرة العميل | يرد على زبائنه نيابة عنه — **مخيف** | يرسل له إيميلاً هو فقط يقرأه — **بلا مخاطرة** |

**استراتيجية:** بِعه كـ**باب دخول**. العميل يشتريه بلا خوف، وبعد شهر من الثقة
يشتري فرز البريد وأنت داخل بالفعل.
