# موقع البورتفوليو — دليل النشر (15 دقيقة)

صفحة واحدة مستقلة بالكامل، بدون أي اعتماديات خارجية. تشتغل بأي استضافة.

## النشر على Vercel (الأسرع)

1. أنشئ مستودعاً جديداً على GitHub باسم `portfolio` وارفع محتوى هذا المجلد فيه.
2. ادخل [vercel.com](https://vercel.com) → **Add New → Project** → اختر المستودع.
3. Framework Preset: **Other**. اترك بقية الإعدادات كما هي → **Deploy**.
4. صار عندك رابط `something.vercel.app` خلال دقيقة.

### دومين شخصي (يستاهل ~10–15$ سنوياً)
اشترِ `muntadhar.dev` أو `muntadhar.com` من Namecheap أو Cloudflare، ثم:
Vercel → Project → **Settings → Domains** → أضف الدومين واتبع تعليمات الـDNS.

> الدومين الشخصي يرفع نسبة الرد على الرسائل الباردة بشكل ملموس. `muntadhar.dev`
> يوحي بمحترف، و`muntadhar-portfolio-final-2.vercel.app` يوحي بطالب.

## قبل النشر — عدّل هذه النقاط

- [ ] أضف رابط LinkedIn في قسم Contact (فيه تعليق يوضح المكان).
- [ ] أضف رقم واتساب **فقط** إذا تريده عاماً — للعملاء الخليجيين مفيد جداً.
- [ ] راجع الأرقام والتواريخ إذا تغيّر شي.

## تحسينات لاحقة (بعد النشر — لا تؤجل النشر لأجلها)

1. **لقطات شاشة للمشاريع** — أقوى تحسين ممكن. صوّر كل مشروع وحطه فوق وصفه.
2. **صفحة دراسة حالة لكل مشروع** — `case-jaz.html` وهكذا، بالقالب الموجود في `../README.md`.
3. **رابط تحميل السيرة الذاتية PDF**.
4. **نسخة عربية** — `ar.html` مع `dir="rtl"` وزر تبديل لغة، للعملاء الخليجيين والعراقيين.

> **قاعدة:** انشر النسخة الحالية اليوم. "جيد ومنشور" يجيب عملاء، و"ممتاز وما زال على جهازك" ما يجيب ولا واحد.
