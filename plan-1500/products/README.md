# المنتجات — Productized Services

> القاعدة: **تبنيه مرة، تبيعه عشر مرات.** كل شي بهذا المجلد لازم يكون قابل للتسليم لعميل جديد بتعديل نص، مو بإعادة بناء.

كل منتج بمجلده لازم يحتوي أربعة أشياء، وإلا مو منتج:

| العنصر | ليش |
|---|---|
| **workflow / كود شغّال** | بدونه هو عرض سعر مو منتج |
| **دليل تركيب بالإنكليزي** | يتسلّم للعميل كما هو — يوفر عليك ساعات دعم |
| **ديمو يشتغل بدقيقة** | العرض يبيع، الشرح ما يبيع |
| **صفحة بيع للعميل** | ترسلها قبل المكالمة، تقصّر المكالمة للنص |

## أفكار للمنتج القادم (بترتيب الأولوية)

1. **التقرير الأسبوعي التلقائي** — جمع بيانات من Sheets/CRM/متجر → تقرير أسبوعي بالإيميل لصاحب العمل. أسهل منتج يُباع لأن كل صاحب عمل يريد أرقامه بدون ما يطلبها.
2. **مساعد RAG على مستندات الشركة** — أسعار أعلى (800 – 2000$)، ويكمّل منتج ١ طبيعياً: يصير مصدر الحقائق اللي يرد منها المساعد.
3. **أتمتة متابعة العملاء المحتملين** — تذكير تلقائي بالمتابعة. تبيعه لأي شركة عندها مبيعات.

**لا تبني الثاني قبل ما تبيع الأول مرتين.** بناء منتجات بلا عميل هو نفس فخ "بناء SaaS خاص" المكتوب بالخطة.
